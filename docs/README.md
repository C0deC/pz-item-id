# PZ Item Bot

Discord bot for the **IBEROZOID_Server** that lets you look up the internal
ID of any Project Zomboid item, in several languages, directly from Discord.

## Commands

- `/getid <name>` — returns only the full item ID (e.g. `Base.Hammer`).
- `/getinfo <name>` — returns a full card: name, ID, type, category, source,
  and icon of the item.

Search works in English and in the supported languages (ES, ES_CL, ES_MX,
FR, DE, IT, PT, RU, PL, NL). If the searched name matches several items, the
bot shows a dropdown menu so the user can pick one.

## Why this project exists

When playing or administering a Project Zomboid server, you often need an
item's internal ID (for example, for admin commands like `/additem`).
Looking it up by hand on the wiki is slow; this bot resolves it instantly
from Discord.

## Architecture

The project is split into two clearly separated parts:

- **`tools/`** — scripts run manually (or whenever the game updates to a new
  version) to generate the data the bot consumes. They never run as part of
  the bot itself.
- **`bot.py`** — the Discord bot. It only reads the files already generated
  in `data/`; it knows nothing about how they were generated.

```
bot-pz/
├── bot.py                        # the Discord bot
├── data/                         # generated by tools/, not version-controlled
│   ├── items.json
│   ├── icon_index.json
│   ├── icons/
│   └── translations.json
├── tools/
│   ├── parse_items.py            # extracts items from media/scripts/*.txt
│   ├── extract_packs.py          # extracts icons from the UI .pack files
│   ├── link_icons.py             # links items to their icons
│   └── extract_translations.py   # extracts item name translations
├── docs/
│   ├── README.md
│   ├── ROADMAP.md
│   └── DECISIONS.md
├── .env                          # not version-controlled (bot token)
└── .gitignore
```

### Why the data doesn't come from the wiki

The original plan was to scrape `pzwiki.net/wiki/PZwiki:Item_list`. That was
dropped because the site has active Cloudflare protection that blocks
automated requests. Instead, data is extracted directly from the game's own
local files (more reliable, and free of the legal/technical issues of
scraping — see `DECISIONS.md`).

## Requirements

- Python 3.11+
- A Project Zomboid installation (build 42) you can access, to be able to
  regenerate the data with `tools/`
- A bot created in the
  [Discord Developer Portal](https://discord.com/developers/applications)

## Installation

```bash
git clone <repo-url>
cd bot-pz
python -m venv venv
source venv/bin/activate        # On Windows: venv\Scripts\Activate.ps1
pip install discord.py requests python-dotenv Pillow
```

Create a `.env` file in the project root with your token:
```
DISCORD_TOKEN=your_token_here
```

## Regenerating the data (`data/`)

Files in `data/` are not version-controlled — they're derived data,
generated by running these scripts in order, pointing them at your Project
Zomboid installation:

```bash
python tools/parse_items.py "<path>/ProjectZomboid/media/scripts" data/items.json

python tools/extract_packs.py <folder_with_UI2.pack_and_IconsMoveables.pack> data/icons

python tools/link_icons.py data/items.json data/icon_index.json data/icons

python tools/extract_translations.py "<path>/ProjectZomboid/media/lua/shared/Translate" data/translations.json
```

## Running the bot

```bash
python bot.py
```
